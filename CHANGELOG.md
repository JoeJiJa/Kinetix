# Changelog

All notable changes to Kinetix will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-08

### Added
- **Rebranding to Kinetix**: Modernized identity as "Kinetix — Next-Gen Glassmorphic Media3 Video Player".
- **Global & Per-Video Persistent Playback Speed**: Flexible playback velocity management with persistent settings either globally or retained individually per video.
- **Dynamic Speed Scrubbing**: Long-press combined with horizontal drag gestures for responsive, real-time dynamic playback speed adjustments.
- **Online Subtitle Search & Auto-Attach**: Built-in subtitle discovery to search and automatically match/attach subtitles directly from online repositories.
- **Animated Glassmorphic Jetpack Compose UI**: Next-generation user interface featuring translucent glass aesthetics, smooth animations, and Material You dynamic theming.
- **High-Speed Batch MediaStore Indexing**: High-efficiency background scanning and batch indexing for instant local video discovery and folder organization with low resource consumption.
